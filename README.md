# LUMÉRA — Cinematic Photography Studio (demo)

Single-file interactive site (HTML + Canvas). No build step.

## Run locally
Open `index.html` in a browser, or: `npx serve .`

## Deploy
**Git:** `git init && git add . && git commit -m "LUMERA" && git branch -M main && git remote add origin <repo-url> && git push -u origin main`

**Vercel:** Import the repo at vercel.com/new → Framework Preset: **Other** → no build command, output directory `.` → Deploy.
